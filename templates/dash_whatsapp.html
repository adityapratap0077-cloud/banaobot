03 Setup guide

  1. Create a Meta app at developers.facebook.com and add the WhatsApp product.
  2. Get a test number: under WhatsApp → API Setup, Meta gives you a free test number — note its phone number ID.
  3. Generate an access token on the same page (temporary is fine for testing).
  4. Paste both above and hit Connect.
  5. Subscribe the webhook: in Meta go to WhatsApp → Configuration → Webhook, paste the webhook URL and verify token from the Status panel, and subscribe to the messages field.
  6. Talk to it: message your test number from WhatsApp — your linked bot answers.

Honest limits: production numbers need Meta's app review and approval; the test sandbox works immediately. The free host sleeps when idle, so the first reply after a nap can take ~30 seconds. Meta retries failed webhooks — the endpoint always answers 200 so retries never pile up.
